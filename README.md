### Requisition Management System

A centralized requisition management web application designed to streamline the process of submitting, transferring, and tracking requisitions between departments.

The system automates the transfer of requisitions from one department to another while keeping both the previous and receiving departments updated throughout the process. It provides visibility into the requisition's current status, history, and assigned department, helping reduce manual coordination and improve overall workflow efficiency.

**What I personally built:**

* Requisition creation and submission workflow
* Automated department-to-department transfer
* Status and department tracking
* Requisition history and updates
* Database structure and relationships
* User interfaces for different departments
* Backend logic for processing requisitions
* Dashboard and tracking functionality
* Debugging and workflow improvements

The main goal was to replace a manual requisition process with a centralized system where departments can easily submit, receive, process, and track requisitions from a single application.
